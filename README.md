# CYword

CYword 是一款支持 Windows 和安卓的开源背单词应用，提供词书计划、词汇掌握和单词搜索。[源码仓库](https://github.com/cheng-yi-cc/CYword)已公开，软件源码使用 [Apache-2.0](LICENSE)；词书、录音等第三方内容的来源与许可材料单独记录在[内容来源台账](docs/CONTENT-SOURCES.md)，不由软件许可证代替。

当前发布版本 Windows 0.4.8 / 安卓 0.1.5（2026-09-25 发布）：安装包预装完整词书、全部发音、原配图和音标字体，首次联网登录后可直接离线学习，无需二次下载；进度默认只保存在当前设备。旧云端进度按账号在本机合并导入一次，之后停止自动同步；云端代码、配置和数据保留以便恢复。详见[离线模式与恢复开关](docs/OFFLINE.md)。0.4.5 / 0.1.2 及更早版本仍采用原联网与同步流程。

当前提供大学英语六级词书，包含 5166 个唯一单词；支持本机进度、单词搜索与发音分割交互，详见[变更记录](docs/CHANGES.md)。计划按“学习 3 天、集中复习 1 天”循环，共 40 天：30 个学习日、10 个复习日。支持计划全日程自由点选，复习覆盖已学唯一单词，默认跳过“已掌握”。

学习顺序在满足熟词依赖后穿插单词与词根组，互相依赖的组会在同一天先安排基础词。同组不跨天，原巧记及关联悬浮窗完整保留；手机和电脑共用顺序，旧学习记录会跟随单词迁移到新的学习日，熟练度和复习记录保留。

单词详情展示“单词巧记”，词根词缀显示“巧记”。仅在页面隐藏重复的“针对第 N 个元素采用词根词缀分析：”引导语，词书原文不变。桌面长难句默认收起，展开时平滑调整三栏宽度；手机通过标签切换，顶部始终保留当前单词和发音入口。

首页始终显示实际学习进度，可直接继续未学词或进入当天复习；查看其他日期时会明确标注预览。每日学习连续进行，评级后进入下一待学词，直到整日学完；不显示分段休息页。词条加载和保存失败可在当前页面重试；保存成功后才推进，复习先加载当前词，再预取后续少量词条。

“单词搜索”按拼写前缀搜索全书：输入 `S` 或 `SY` 即展开候选，回车后显示完整分页结果，始终按词书学习顺序排列。点击候选或结果打开详情，每轮需评级后才能前进。搜索评级只更新词汇状态，不增加计划曝光或复习记录；任一评级均算已学习，计入相关学习日的初始进度，完成当天剩余未学词即可完成当天。复习日仍需单独判断。

“词汇掌握”显示全书已掌握、未掌握、不清楚、未学习的数量。待巩固列表自动收录已学过且评级为未掌握或不清楚的词，支持筛选、搜索、详情和重新评级；改为已掌握后自动移出，无需手动收藏。

列表仅有“未掌握”“不清楚”两个分类，默认显示未掌握。计划页固定标题和进度卡，仅下方日期卡片滚动；左侧显示当前计划天数/总天数（如 `1/40`），右侧显示当天已完成数/当天安排数。

点击词汇会平滑展开全屏详情，按当前分类及搜索结果的顺序浏览。重新评级后自动进入下一词，可回看上一个；本轮已评级词支持直接前进。返回列表保留原分类、搜索和滚动位置，评级只更新掌握情况，不推进当天计划。

首次使用通过邮箱 6 位验证码注册并登录。应用保留按账号分开的本机记录，不再自动跨设备同步。桌面进度保存在 `userData/accounts/<账号哈希>/progress.json`，不进入安装包。Windows 0.4.5 将桌面 `userData/session.json` 中的令牌改为系统加密，安卓 0.1.1 使用 Keystore 加密令牌，并迁移旧明文会话；浏览器预览仍使用 localStorage。旧版进度只自动迁移到升级启动时已登录的账号，并保留原文件。

云端接口已部署并保留。新版默认只从中导入旧进度一次，同一账号的后续学习记录不再自动跨设备同步。已发布旧版的同步行为与部署记录见 [安卓与同步说明](docs/ANDROID.md)。

## 安卓与手机预览

```powershell
npm run dev:mobile
```

浏览器访问 `http://127.0.0.1:5173/`，同一 Wi-Fi 的手机可用电脑局域网 IP 的 5173 端口预览。开发环境使用模拟登录与内存中的旧进度服务，不会上传到真实账号。设置 `$env:CYWORD_REAL_AUTH='1'` 后再启动，可改用生产登录与旧进度导入，词书仍默认直读本机；默认仍只保存本机进度。

```powershell
npm run android:release
```

需要 JDK 21 和 Android SDK 36。输出 `release/CYword-Android-0.1.5.apk`，支持 Android 7.0 及以上，首次联网登录后离线使用。构建脚本通过 `CYWORD_JAVA_HOME`、`ANDROID_HOME` 选择工具链；首次正式构建在用户目录 `.cyword/` 创建可持续升级的签名密钥，务必备份。更多说明见 [ANDROID.md](docs/ANDROID.md)。

Windows 安装程序首次安装时可选择目录；运行新版安装包会默认沿用旧目录并原位升级。Windows 0.4.5 起，启动时通过官网 `/downloads/latest.yml` 检查更新并自动下载，下载完成后点击一次立即安装，失败可重试；安装器与差分文件均从官网 R2 下载。已安装的 0.4.4 仍需手动下载一次，升级到 0.4.5 后生效。

安卓启动及返回前台检查更新，“我的 → 检查更新”可手动检查。0.1.5 起点击下载会复用已安装 APK，仅获取变化部分，校验后由用户点击交给系统安装；失败不自动下载全包。0.1.4 及更早版本需完整升级到 0.1.5 一次。Windows 自动更新优先使用差量，缓存缺失或差量失败时可能回退全包；首次安装始终使用完整包。

## 本地预览

两端已提供「以音记形」「以熟带生」：前者默认显示完整拼写，单击切换分块；点击音标发音时临时分块，结束、停止或失败后恢复原状态，另可展开音形对照；后者位于词根词缀分析之后，只从本书计划中更早出现或实际学过的词中选择一个参照，没有合格参照则隐藏。六级 5166 词均有审核记录，2180 词有词义参照候选；验收范围见[增强数据说明](books/cet6/enhancements/README.md)。Windows 0.4.5、安卓 0.1.1 与增强词书数据已于 2026-09-20 一并发布。

建议使用 Node.js 24 LTS，与发布工作流一致。首次运行：

```powershell
npm ci
npm run dev
```

开发窗口会自动打开，默认模拟登录，直接读取本地编译词书；配图和发音按需读取已有 `book` 目录或 `release/` 中的完整 APK，无需再次下载或解包。保留已有 APK，或用 `CYWORD_PREVIEW_BOOK` 指定资源目录。纯浏览器运行 `npm run dev:web` 后访问 `http://127.0.0.1:5173/`；`CYWORD_REAL_AUTH=1` 切换生产认证和旧进度导入，不启用上传。重新编译词书后刷新即可，无需清理数据库。旧下载流程仅在 `VITE_CYWORD_BOOK_DOWNLOAD=1` 时启用，见 [OFFLINE.md](docs/OFFLINE.md)。桌面安装包由以下命令生成：

```powershell
npm run dist
```

安装程序输出到 `release/CYword-Setup-<version>.exe`。同目录的 `latest.yml` 和 `.exe.blockmap` 是应用内更新所需文件，发布时必须一起上传。Windows 可能因安装包未签名而显示 SmartScreen 提示。

## 官网本地预览

官网位于 `website/`，与桌面应用分开运行，面向普通用户提供功能体验、下载和安装指南。已部署到 Cloudflare Pages，正式域名为 <https://cyword.chengyi.me/>。下载通过同域 `/downloads/` 路径读取 R2 安装包，支持断点续传；GitHub 仓库与 Release 现已公开，官网页脚提供开源链接。现有自动更新继续使用官网地址。公开反馈与账号删除申请邮箱为 [cyi907369@gmail.com](mailto:cyi907369@gmail.com)。本地预览：

```powershell
npm run dev:site
```

浏览器访问 `http://127.0.0.1:5174/`。不需要启动 Electron，也不需要生成词书数据。本地预览通过代理读取官网的 Windows 和安卓最新版信息。页面里的学习体验使用少量独立示例，不会修改桌面端或浏览器版软件的学习进度。

```powershell
npm run build:site
npm run preview:site
```

官网独立构建到 `dist-site/`，构建预览地址为 `http://127.0.0.1:4174/`。页面运行时读取 R2 的最新版指针，标签工作流成功发布后会自动更新版本、下载按钮和校验值，无需重新构建官网。`website/src/release.ts` 只保留指针不可用时的回退版本。结构、版本维护与检查方式见 [官网说明](docs/WEBSITE.md)。

下载接口测试和官网发布：

```powershell
npm run test:site:download
npm run deploy:site
```

测试只使用本地模拟 R2，不上传测试文件；部署需要已登录 Cloudflare，更新 Pages 的 `main` 生产环境。不要再用纯静态 ZIP 上传，以免漏掉下载函数和 R2 绑定。普通网站代码提交不会自动部署；推送版本标签可自动构建发布；已有验收安装包可先上传 GitHub Release 草稿，再发布 Release，由工作流复用原件上传官网 R2。生产已部署兼容 v1/v2 发布清单的下载函数；新环境须先部署兼容函数再上传新格式指针；发布脚本会检查线上能力、元数据和 blockmap 与安装器的一致性，拒绝覆盖不同内容的同版本文件，失败重跑复用已发布资产。

## 校验与测试

```powershell
npm run data:verify
npm test
npm run test:ui
npm run test:site:ui
npm run build:web
```

`data:verify` 校验词书文件集合、每张表的行数、单词外键、六级核心统计及增强审核记录；`test` 还会生成服务端词书分片，并验证排课、同步、认证并发和发布校验。`test:ui` 使用本机 Chrome 运行学习交互、失败恢复和移动布局回归，使用独立测试词书与模拟账号，不写真实学习进度。编译后运行 `npm run data:audit:pronunciation`、`npm run data:audit:meaning-bridges` 可重建逐词检查报告，报告写入 `.work/`，不提交。原始内容及第三方音频的来源、授权证据缺口见[内容来源台账](docs/CONTENT-SOURCES.md)。

## 目录

- `books/cet6/`：六级词书清单、19 张规范 CSV、记忆增强及逐词审核源数据。
- `scripts/`：词书校验与编译、服务端词书分片和上传、官网下载测试及 R2 版本原子发布脚本。
- `src/`：React 界面、排课与进度逻辑。
- `website/`：独立官网，含交互示例、软件下载、安装指南和常见问题。
- `electron/`：Windows 桌面外壳和本地文件读写。
- `tests/`：自动化测试。
- `data/`、`dist/`、`dist-site/`、`release/`：构建生成物，不提交到 Git。

更多说明见 [变更记录](docs/CHANGES.md)、[词书数据](docs/DATASETS.md)、[架构](docs/ARCHITECTURE.md) 和 [运行手册](docs/RUNBOOK.md)。
