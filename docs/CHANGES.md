# 变更记录

## 0.5.0 · 本地交付，尚未正式发布

2026-09-17 至 2026-09-19 完成功能开发。2026-09-20 收尾核对：39 项自动测试已通过，移动/桌面浏览器验证通过；APK 已签名校验，Windows 安装包已生成。无安卓真机验证，云同步及官网修改尚未部署。

- 2026-09-19 重排学习顺序：满足熟词前置依赖后穿插单词与多词根组；已有释义的词根回指保留原文和悬浮窗。互相依赖的词根组同日完成，必要时先穿插基础词，消除旧算法强行打破依赖的情况。手机和桌面共用编译顺序，按曝光身份迁移旧学习日，不丢熟练度、不重复计数；原巧记严禁修改已写入项目约定。
- 2026-09-19 界面调整：删除“待巩固”汇总分类，仅保留未掌握/不清楚；计划页改为固定标题和双栏进度卡，左侧显示当前天数/40，右侧显示当天已完成/安排词数。仅日期卡片独立滚动，移除学习日/复习日图例和四格统计说明。
- 移除词汇掌握导航数字角标；词汇详情改为带进出动画的全屏界面，固定返回及评级/前后导航，按打开时列表顺序跨页浏览。必须重新评级才可推进，本轮回看已评级词可直接前进，最后一词评级后返回列表；保留原筛选、搜索和滚动位置，支持安卓返回键与键盘导航。
- 将两端生词本改为“词汇掌握”：统计全书四类状态，自动收录已学过且未掌握/不清楚的词，支持状态筛选、中英文搜索、分页与重新评级；已掌握后移出列表，保留原学习记录。官网演示、说明和 FAQ 同步修改。
- 修复计划卡片在窄屏或放大字号时词数与进度条重叠的问题；“我的”入口移除含混的分隔点，增加展开箭头，并在账号菜单解释同步状态。

- 新增 Capacitor 安卓客户端，与 Windows 端共用词根排课、三档评级和累计复习逻辑；手机支持底部导航、固定评级栏、单词/词根/长难句切换和点按关联词。
- 新增按账号隔离的本机存储、进度合并与 `/api/progress` 认证接口；D1 修订号检查防止并发覆盖，已完成曝光合并，熟练度和收藏按变更时间合并，删除收藏保留标记。进度压缩后存储以支持完整词书的复习记录。
- 新增 Android 正式签名构建脚本、移动端预览命令与同步的单元/Worker+D1 集成测试。
- 0.5.0 客户端的云端同步需要先执行 `website/migrations/0001_progress.sql` 并部署官网函数；本机 Cloudflare 授权在 2026-09-17 缺少 D1 写入范围，线上开通状态须以部署验证为准。

## 0.4.3 · 2026-09-04

- 优化背词交互与熟练度判断流程：学习会话移除未评级状态下的「下一个」按钮并阻断键盘右方向键跳过，强制通过三档掌握熟练度（未掌握/不清楚/已掌握）判断后自动推进至下一词；底栏默认呈两端对齐（左侧「上一个」、右侧「空格 发音」）；点击「上一个」回看已评级词时动态显示「下一个」按钮并恢复方向键推进，支持直接前进或重新评级后推进。
- 主页进度指示由静态水平裁切线升级为 SVG 双层动态液体波浪：「Day {day}」字形整体作为液体容器，前浪（陶土红，4.2s 周期）与后浪（半透明陶土红，7.5s 周期）双向错频流动，水面随学习进度平滑上涨，GPU `@keyframes` 驱动，无 CPU 额外负担。

## 0.4.2 · 2026-09-03

- 新增单词交叉引用悬浮卡片（WordHoverPopover）：巧记、词源解析与单词详情中的 Markdown 链接（`[[word]]` 与 `[[target|display]]`）支持鼠标悬浮即时展开单词卡片，呈现音标发音、简明释义、联想巧记、构词拆解及精选例句；自动标识该词在六级词书中是否已学或所属学习天数，无需中断当前背词会话。
- 排课算法引入拓扑排序优化：构建脚本自动解析单词巧记与词源中的熟词及前置依赖关系（“基于/熟词[[xxx]]”），对词根组及同组内单词分别执行拓扑排序，优先安排基础熟词；其中循环依赖曾被强行打破，0.5.0 改为区分词根回指与熟词依赖、同日处理互相依赖的组。
- 长难句断句切片自动清洗：构建管线合并长难句分段中的尾随标点符号，杜绝空切片与孤立标点独立成行的渲染瑕疵。
- 词书计划支持全天数自由点选：计划页（PlanView）解除仅允许进入当前进度天的交互限制，允许用户随意点击任意天数卡片，随时查看历史或未来各天的单词学习与集中复习内容。
- 官网沉浸式记忆视窗升级为客户端同款三栏独立滑动交互：首屏 1:1 动态还原桌面客户端三栏（词根词缀、核心巧记与真题例句、长难句精读）布局，三栏各自具备完全独立的上下滑动轨道；加入 `overscroll-behavior: contain` 阻断滚动穿透，定制桌面原生质感细滚动条，并配套真人发音声波动态可视化与长难句语法成分高光流光联动。
- 接口稳定性与开发韧性增强：桌面端与网页端请求添加 `AbortSignal.timeout` 超时保护，支持通过环境变量 `CYWORD_BOOK_API_URL` 自由覆盖远程词库服务地址，本地 Vite 开发环境提供 `/api/books` 代理直连生产接口。

## 0.4.1 · 2026-09-02

- 修复正式环境在缺少邮件密钥时错误进入模拟发信、回显并自动填入验证码的问题；生产认证现在缺少 `RESEND_API_KEY` 或强随机 `JWT_SECRET` 时直接拒绝服务。
- Resend 发信人改为已隔离的 `login@auth.cyword.chengyi.me`，邮件发送失败会撤销不可用验证码，不再让用户进入无意义的重发冷却。
- 验证码邮件正文标题简化为 `CYword`，原绿色视觉替换为与客户端一致的陶土橙品牌色。
- 正式客户端拒绝服务端调试验证码字段；本地 Vite 开发环境仍保留明确隔离的模拟验证码流程。安装包继续只包含应用代码，不包含 Electron `userData` 中的邮箱、会话或学习进度。
- 恢复权威 Cloudflare DNS 中的 `cyword` 官网记录，并为专用 Resend 发信域补齐 DKIM 与退信跟踪记录；根域和 `www` 保持不变。

## 0.4.0 · 2026-09-02

- 新增邮箱验证码（OTP）免密注册与登录系统：接入 Cloudflare D1 存储用户基础信息与临时验证码，通过 Resend 发送验证码邮件，使用 Web Crypto HMAC-SHA256 签发 JWT 会话。
- 桌面客户端会话持久化存储在 `userData/session.json`，未登录时自动唤起登录弹窗，登录后在侧边栏底部展示用户邮箱并提供注销入口；背单词学习进度继续保存在本地 `userData/progress.json`。
- 后端新增 `/api/auth/send-code`、`/api/auth/verify-code` 和 `/api/auth/me` Pages Functions 路由，具备 60 秒重发冷却与 5 次错误尝试防暴力破解机制；本地开发环境内置自动回显模拟发信。
