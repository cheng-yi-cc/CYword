# 本地词书与进度

当前正式版本 Windows 0.4.8 / Android 0.1.5（2026-09-25 发布）将完整六级词书、全部 5166 条发音、正文原配图及音标字体放入安装包。Windows 0.4.6 / Android 0.1.3 仍使用首次下载流程；更早版本采用原联网与同步机制。

## 用户流程

1. 首次使用通过邮箱验证码联网登录；已有受保护会话可离线启动。
2. 登录后直接进入首页。词书正文和音频从安装目录读取，不再显示“下载词书”，也不在首次启动时将整本资源复制到用户存储。
3. 每日评级后连续进入下一待学词，整日完成后返回安排；词根分组、熟词依赖、三学一复习和评级保存规则保持不变。
4. 进度仍按账号保存在原位置。升级使用新版安装包资源，原 IndexedDB 下载缓存及学习记录不删除、不覆盖；退出登录也保留本机进度。首次登录、再次登录和旧云端导入仍需要联网。

## 资源构建与读取

- `npm run build` 先校验并编译规范词书，`scripts/build-bundled-book.mjs` 再生成 `.work/bundled-book/`。逐词保留原 JSON 正文；按内容生成独立数据版本。全部原发音在构建机下载，限制并发和重试，校验 MP3/WAV/Ogg 文件头，并记录字节数与 SHA-256。
- 部分上游 `.mp3` URL 实际为 Ogg Vorbis；包内文件扩展名按真实文件头选择，词条原 URL 和录音字节保持原样。
- 正文和悬浮卡的 Markdown/HTML 图片在构建时收集、校验文件头与 SHA-256，缓存到 `.work/book-images/`；同字节图片在安装包中去重。渲染时只替换图片传输地址为本地文件，规范词书正文、巧记引用和原图像素均不修改。PNG 经 `sharp` 无损转码、逐图比较解码后的 RGBA 像素，只有像素一致且文件更小才使用 WebP；不满足时保留原文件。构建缓存可复用，也可在收尾时清理；清理后下次构建会重新下载和转码。缺失配图同样阻断构建。
- 构建音频缓存为 `.work/book-audio/`，复用前检查哈希；下载失败阻断打包。只有全部资源成功才生成完成清单。Vite 把该目录复制到 `dist/book/`，Electron 和 Capacitor 均打包 `dist/`；官网独立构建不携带这些资源。
- `src/bundled-book.ts` 校验目录、版本和词条身份。Windows 通过限定文件名的只读 IPC 读取 JSON，安卓读取应用本地资源，音频直接使用包内地址。不会回退到网络词书请求，不依赖 IndexedDB 容量或旧的下载完成标记。
- Windows 0.4.8 起通过 `asarUnpack` 将整个 `dist/book/` 放入安装目录的 `app.asar.unpacked/`；Electron 保留原虚拟路径，读取无需复制。词书文件在 NSIS 中独立压缩，程序变化不会重压同一个巨大 ASAR；从旧布局首次迁移的更新仍较大。
- `WordResourceCache` 继续限制为 256 个详情，按当前词和后续少量词预取。学习进度、账号会话保护及一次性导入标记的位置与格式不变。
- 所有音标入口使用随包分发的 Gentium 7.000 字体，覆盖词书音标与音形分块的全部 45 个不同字符。原数据不修改；字体来源和许可见 [内容来源](CONTENT-SOURCES.md)。

## 旧云端进度一次性导入

默认本地模式为每台设备的每个账号读取一次 `GET /api/progress`。先与本机进度合并并成功保存，再写本机导入标记；不发送 PUT，不删除云端原记录。合并复用已有时间戳、曝光键和复习去重规则，下载期间或导入请求期间产生的新评级不会被旧快照覆盖。

导入标记在桌面保存为该账号目录的 `cloud-import.json`，安卓/浏览器保存为 `cyword-cloud-import:<账号 ID>`。安卓通过原生同步提交确认落盘。标记保存失败可重试，合并是幂等的。已完成导入的账号再次启动、恢复网络或返回前台都不会再请求学习进度接口。

网络或导入失败不影响本地学习。未完成时可从状态入口重试，恢复网络或回到前台也会补试。旧令牌返回 401 时提示重新登录以导入旧记录，不删除已登录设备的本地会话。退出登录只等待本机保存，不会因网络不通阻止退出；本机写入失败或清除会话失败仍明确提示。

正常登录的账号入口仅显示头像与邮箱前缀，保存状态和退出入口收在账号菜单。JWT 到期或进度接口返回 401 时，入口显示“未登录”，不自动弹窗、不清除受保护会话，也不改变本机进度归属。点击后可重新验证邮箱；同账号继续原记录，切换账号则读取该账号独立进度。失效期间暂停远端请求并继续串行落盘，重新登录后恢复未完成导入；显式云端模式同样保留本机学习。断网或服务错误不直接判定为失效。

## 保留与恢复云端模式

认证服务继续运行。D1 表、旧学习记录、Pages 路由、R2 桶、Secrets、Wrangler 配置、发布流程和原 `ProgressSync` 云端模式均保留。本次改动不删除或停用生产资源，旧客户端仍可能继续上传。

默认构建使用本地模式。需要恢复云端同步时，在构建前设置：

```powershell
$env:VITE_CYWORD_PROGRESS_MODE = 'cloud'
npm run build
# 或运行 npm run dev / npm run android:debug
```

恢复后按原协议合并本机与云端进度，并用修订号处理 409。改回默认模式：

```powershell
Remove-Item Env:VITE_CYWORD_PROGRESS_MODE -ErrorAction SilentlyContinue
```

它是构建时开关，需要重启开发服务器或重新构建安装包；`CYWORD_REAL_AUTH=1` 切换开发时的认证、旧进度导入，不会自动打开云端上传。默认预览仍直读本地词书；显式启用旧下载流程后，该开关才同时切换词书 API。

## 开发预览直接读取本机资源

`npm run dev`、`npm run dev:web`、`npm run dev:mobile` 默认通过 `/__local-book/` 读取 `data/`，不显示下载页、不复制到 IndexedDB。版本哈希包含目录与全部词条正文，排除编译时间；重新编译后刷新页面即可看到新内容，账号进度和旧缓存均保留。

媒体按以下顺序查找：`CYWORD_PREVIEW_BOOK` 指定目录、`dist/book/`、`.work/bundled-book/`、安卓已同步资源目录、`release/CYword-Android-*.apk`（版本倒序）。只读请求中的单个文件并验证清单哈希；从 APK 按 ZIP 偏移读取，不全量解包。保留本机已有的完整 APK，收尾删除 `.work/` 不会导致预览重新下载。缺失媒体明确返回错误，不暗中全量联网补齐。词书正文始终取当前编译结果，不从旧 APK 取词条。

仅回归旧下载路径时设置 `$env:VITE_CYWORD_BOOK_DOWNLOAD='1'`，重启服务。再设置 `$env:CYWORD_REAL_AUTH='1'` 可联调旧线上词书。完成后移除这两个环境变量并重启。应用界面测试在独立端口显式启用旧流程，继续覆盖 IndexedDB 失败恢复。

## 本地验收

`npm run dev` 预览桌面；`npm run dev:mobile` 预览手机布局。安装并首次登录后直接进入学习，再断网、退出并重新打开安装应用，检查学习、复习、搜索、词根悬浮窗、长难句与播放发音；重新评级后重启，检查进度保留。默认开发预览重新编译后只需刷新；仅在显式回归旧下载流程时，需清除 `cyword-offline-books` 数据库后重下，不要清理 localStorage 或账号进度。
