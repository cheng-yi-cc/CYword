# 本地词书与进度

Windows 0.4.6 / Android 0.1.3 起使用本文流程；旧版 0.4.5 / 0.1.2 仍采用原联网与同步流程。

## 用户流程

1. 首次使用通过邮箱验证码联网登录。已经登录的设备继续使用受保护的本地会话，离线启动不调用认证接口。
2. 点击“下载词书”，保存完整六级词书和全部发音。文字按 64 词分批下载，音频最多 4 个并发；完成的分批立即保存，失败后点击“继续下载”只补齐缺少的内容。全部保存成功才进入首页。
3. Windows / 安卓安装应用重启后从本机读取目录、释义、巧记、例句、词根、长难句和发音，无需网络。音频从本机生成临时 Blob URL 播放；只保留最多 8 个音频 URL，正文不会被改写。
4. 进度仍按账号保存在原位置。新评级先成功落盘再推进界面，默认不上传。退出登录保留词书与进度，再次登录需联网；卸载或清理应用数据会删除本机记录，需要自行保留备份。

浏览器用于开发预览，下载后的词书保存在该浏览器、该站点的 IndexedDB；加载开发页面本身仍需要本地开发服务器，不把它当作已安装的离线 Web 应用。手机浏览器的 HTTP 局域网预览同样需要开发服务器运行。

## 本地存储

- `src/offline-book.ts` 使用 IndexedDB `cyword-offline-books`，Windows 存在 Electron 用户数据目录的 IndexedDB 内，安卓存在应用 WebView 的私有数据目录内。词条键包含词书代码、版本和单词 ID，音频按原 URL 去重。
- `meta` 保存当前目录和完成标记，`words` 保存原词条，`audio` 保存音频 Blob。成功提交所有文字和音频后，才提交 `ready: true`。中断下载保留目录版本，不混用另一版本的分片。
- 内存里的 `WordResourceCache` 仍限制为 256 个详情；其数据源改为本地词书库。安装包不塞入完整词书，旧的只读目录与词书接口继续作为首次下载来源。
- 桌面进度仍为 `userData/accounts/<账号哈希>/progress.json`，安卓仍使用 `cyword-progress:<账号 ID>`；浏览器使用 localStorage。没有迁移或改写原有会话加密格式。
- Windows 音频由主进程下载，安卓使用原生 `CapacitorHttp`，仅允许词书 CDN 的固定音频路径。浏览器预览经 Vite 的 `/__book-audio/audio/<哈希>.(mp3|wav)` 限定代理下载，以处理音频 CDN 不提供 CORS 响应头的情况。未新增线上音频代理。

## 旧云端进度一次性导入

默认本地模式为每台设备的每个账号读取一次 `GET /api/progress`。先与本机进度合并并成功保存，再写本机导入标记；不发送 PUT，不删除云端原记录。合并复用已有时间戳、曝光键和复习去重规则，下载期间或导入请求期间产生的新评级不会被旧快照覆盖。

导入标记在桌面保存为该账号目录的 `cloud-import.json`，安卓/浏览器保存为 `cyword-cloud-import:<账号 ID>`。安卓通过原生同步提交确认落盘。标记保存失败可重试，合并是幂等的。已完成导入的账号再次启动、恢复网络或返回前台都不会再请求学习进度接口。

网络或导入失败不影响本地学习。未完成时可从状态入口重试，恢复网络或回到前台也会补试。旧令牌返回 401 时提示重新登录以导入旧记录，不删除已登录设备的本地会话。退出登录只等待本机保存，不会因网络不通阻止退出；本机写入失败或清除会话失败仍明确提示。

## 保留与恢复云端模式

认证服务继续运行。D1 表、旧学习记录、Pages 路由、R2 桶、Secrets、Wrangler 配置、发布流程和原 `ProgressSync` 云端模式均保留。本次改动不删除或停用生产资源，旧客户端仍可能继续上传。

默认构建使用本地模式。需要恢复云端同步时，在构建前设置：

```powershell
$env:VITE_CYWORD_PROGRESS_MODE = 'cloud'
npm run build
# 或运行 npm run dev / npm run android:debug
```

恢复后按原协议合并本机与云端进度，并用修订号处理 409。改回默认模式：

```powershell
Remove-Item Env:VITE_CYWORD_PROGRESS_MODE -ErrorAction SilentlyContinue
```

它是构建时开关，需要重启开发服务器或重新构建安装包；`CYWORD_REAL_AUTH=1` 仅切换开发时的认证、旧进度导入及词书服务地址，不会自动打开云端上传。

## 本地验收

`npm run dev` 预览桌面；`npm run dev:mobile` 预览手机布局。首次登录后完整下载词书，再断网、退出并重新打开安装应用，检查学习、复习、搜索、词根悬浮窗、长难句与播放发音；重新评级后重启，检查进度保留。开发预览修改词书数据后，需要在浏览器开发工具中只清除 `cyword-offline-books` 数据库并刷新、重新下载，不要清理 localStorage 或账号进度。

- 103 项自动化测试和 18 项界面回归通过，覆盖下载中断、错误分片、失败提交、版本隔离、播放竞态、只读导入、写盘失败、账号切换、零上传和重载后使用已下载内容。
- Chrome 独立预览目录实际下载全部 5166 词及 5166 条原音频，包括 72 条 WAV；中断后复用了之前保存的 31 条音频。屏蔽词书、音频及进度接口后重载，成功打开 `enter`、播放本地发音、评级并再次重载保留该评级；云端 PUT 为 0。浏览器报告的该站点存储占用约 116 MB，仅作本次环境参考。
- Windows Electron 使用隔离账号与两词验收词书，实际通过主进程下载 MP3 / WAV，经受保护的本地会话和账号进度落盘，彻底关闭再以禁止联网的测试环境启动后，继续下一词并播放本机发音；一次性导入标记和已学记录保留，冷启动后网络请求为 0。
