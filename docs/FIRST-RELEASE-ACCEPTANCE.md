## 已实现的规则和保障

- 三档有效评级均算已学。所有复习入口共用前置学习/复习检查，锁定时不创建队列。合法空队列须明确确认；课程版本和轮次身份稳定。
- 当前日为第一个未完成日，与自然日期无关；全计划完成有结束状态。会话绑定启动日，用户日期预览不被同步强制切换。
- 本机保存、合并和确认串行；持久化成功才推进，restored/pending 与进度同写。首次恢复失败不上传空进度；过期仍可离线学习，账号迟到响应隔离。
- 同词采用逻辑版本 (counter, actor)，已观察版本加一，离线同计数按 actor 字典序收敛，允许降低熟练度，不依赖设备时钟。不同词、曝光及同轮复习事实合并保留。
- Windows 原子替换、同步落盘、有效副本和异常原件保留，DPAPI 会话；Android Preferences 原生 commit 保存主记录与副本，Keystore 保护会话。关闭、退出、切换账号及更新共享保存保护。
- 词条/图片/发音失败局部处理；损坏词条不自动评级，根及关键内容有错误边界。完整词书、6179 个媒体文件和字体随包离线读取。
- 认证保留同邮箱冷却、错误次数及原子核销，增加全局 200 封/小时、1000 封/日预算、来源检查和发信超时，不对校园共享 IP 设置低阈值。
