# 四级词库字段与编写规范

2026-09-17 采用用户提供的《四级词汇整理方案》：[共用内容标准](../shared/STANDARD.md) 是新增内容的上位规则。基础词和独立派生词保留；词形疑点逐词审计，不用四、六级的总数倒推删词。构词权威登记迁至 `authoring/shared/morphemes.csv`，本目录旧登记表为兼容投影。

前置词必须显式登记并校验无循环；正文链接不自动等于前置要求。真实词根的身份和是否单独排课分开处理。100 词试验仅将关联至少两个目标词的词根编组，单词详情仍保留完整构词；现有六级排课保持原规则。

本目录是阶段 1—6 的编辑材料，不是已经发布的词书。完成内容后，按本规范导出到 `books/cet4/`，保持六级的 19 张 CSV 表头和字段顺序。阶段 1 不创建空内容的正式 `book.json`，不把尚未编写的词条标为可学习。

2026-09-17 用户要求自主推进，取消中途确认等待。未确定的事实先查参考；仍无依据时保存明确的草稿状态，不伪造词源、复核或完成状态。最终由用户逐词审查。

新增初稿源位于 `content/*.tsv` 与配套 `*-reading.tsv`，词典原始参考独立保存在 `references/lexical.csv`。初稿检查只核对数据可读、目标词与词形、阅读分段、身份和参考，不把它自动提升为 reviewed；构词、逐段释义和二次核实完成前不进入正式词书。

巧记继承六级的熟词联系、字形提示、适度谐音和具体场景。每词选择最直接的一条记忆路径，不必重复“针对第几个元素”“联系含义综合考虑”；短词可以整体记，派生词可以接着词基记。虚构场景只承担助记作用，不能据此登记真实词根。六级同词仅作对照，不自动复制或将其词源当成核验依据。

## 收词与词数

1. 以 `source_entries.csv` 的考纲定位为入口。主词条有 ★ 的出处属于六级；无 ★ 的出处属于四级。附列词沿用所在行的等级，记录为编辑解释，不冒称逐词单独标级。
2. 只收考纲明确列出的词形；不自动生成所有派生词、屈折词或近义词。用户已确认将四级行明确附列的词形独立收录，范围见 `scope_decision.json`；最终冻结清单为 `wordlist.csv` 的 6,161 条。
3. 同形词按一个学习词条合并，保留所有来源及原书上标编号；阶段 3 必须核对多义、多音和词性，不因合并而丢失必要用法。字形带重音符号的 `résumé` 与 `resume` 不自动合并。
4. 英美拼写变体共用词条，变体列表保存在 `variants_json`。独立词、缩略词、不同性别称谓和不是单纯拼写差异的词形分开，例如 `insure/ensure`、`prince/princess`、`exam/examination`。`a/an` 分为两个学习词条。
5. 连字符与词中撇号保留；原文确为短语的按一个短语词条保留空格。不能把 `according to` 合成 `accordingto`。不额外增加词组清单。
6. `/`、括号可选字母和 `/-ise` 等缩写的每一种记法均在 `normalization_rules.json` 登记展开结果。特殊记法和疑似印刷问题显式记账，不靠统一截尾规则蒙混处理。
7. 单词 ID 由首次冻结的规范拼写产生，形式为 `cet4-w-` 加 SHA-256 前 20 个十六进制字符。输入是 `cyword:cet4:` 加小写规范拼写。词序变动不改 ID；内容编写开始后，拼写修订须保留原 ID 并记录迁移，不直接重跑初始生成器改写身份。
8. 印刷总数、可枚举源词目和最终学习词条数分别记录；发布时以冻结词表为准，不补造差额。

## 表结构与填写方式

`schema.json` 冻结 19 张表的全部 173 个字段。六级现有字典只描述 162 个字段，缺少字典与表目录自身的 11 个字段；本规范补足它们，六级原文件不变。

`field_policy.csv` 为每个字段规定来源方式、必填条件、默认值、未来编辑对象的逻辑路径及具体规则。`editorial_source_path` 是编辑协议中约定的逻辑位置，不表示该 JSON 内容现在已经存在。旧接口路径只作对照，不得照抄为四级数据的实际采集来源。

| 内容 | 编写与导出规则 |
| --- | --- |
| `books`、`words` 身份信息 | 固定 `book_id=cyword-cet4`、`book_code=cet4`；单词引用冻结 ID。 |
| 音标、中文释义 | 阶段 3 核实音标、原创释义。考纲没有这些信息，逐项记录参考来源。 |
| 巧记、构词与词源 | 分清事实和联想；真实词根要有依据，无真正词根就独立成组。 |
| 普通例句、搭配、长句及解析 | 按样板标准原创和复核；长句来源标明 `cyword_original`。 |
| 真题和词频 | 有可靠语料才创建记录；无记录不是零次，不能用模拟内容补齐。 |
| 构词与正文链接 | 所有目标先登记再引用；同一根 ID 的类型、含义和拼写必须一致。 |
| 用户进度 | 初始布尔值 `false`，次数 `0`；不携带六级账户进度。 |
| 权限、追踪、隐藏提示 | 无关的上游字段留空；不伪造购买状态、授权期限、追踪号或隐藏提示。 |
| 目录、字段字典、计数 | 由实际材料计算。正式表目录包含自身共 19 行；字段字典完整描述 173 个字段。 |
| 原始字段盘点 | 只盘点实际存在的本项目编辑对象；对象协议在阶段 2 固定前可零行，不复制六级接口出现次数。 |

CSV 使用 UTF-8、标准引号转义。空值用空单元格，不写字面字符串 `null`；布尔值为小写 `true/false`，整数不加千分位。JSON 字段必须是可解析 JSON，不使用 Python 列表表示法。

## ID 与引用

- `word_id`：冻结词表的稳定 ID；以 `word_sources.csv` 追溯考纲。
- 例句、长句、搭配：在词条内登记稳定局部编号，如 `<word_id>:example:001`。修改翻译不改 ID；删除的编号不再复用。
- 构词元素：先登记 `root_type`、语言、规范形式、义项键及证据，再分配稳定 ID，例如 `cy-morph-` 加身份键的 SHA-256 前 20 位。身份键约定为 `类型|语言代码|规范形式|义项键`；义项键一经登记不能随着中文措辞调整而变化。
- 同形异源、同形不同类的元素使用不同 ID；真正词根的变体形先登记再共用 ID。不得仅因拼写相同合并词根。
- `word_markup_links` 和 `root_markup_links` 由正文解析生成；`target_type` 与目标实体一致。书外词可写为普通扩展文本，不制造本书的悬空 ID。
- `relations` 的 `word_id + relation_type` 唯一；`relation_words` 的父分组和关联词均存在。
- 原字典把 `long_sentences.sentence` 也标成主键；本书采用表目录声明的 `long_sentence_id`，句子正文不当作数据库主键。

## 解析与计数

所有 `*_index` 从 0 开始；冻结词表的 `word_order` 从 1 开始。长句片段引用仅指向同一句子的 `segment_index`。拼接片段应还原原句，允许规范的空格处理，不能丢词或改标点。

例句数量、根记录数、关系分组数、词频记录数从各子表计算。`words.frequency_count` 表示词频记录条数，`frequencies.frequency_count` 表示语料实际出现次数，两者不能混用。

`day_id/day_number/order_in_day` 不伪装成原始采集计划，保持空值；阶段 7 从真正词根和依赖关系生成新学习日。多词根词可多次曝光，不存在唯一“原始学习日”。

## 来源、状态与验收

`evidence.csv` 记录教学字段引用的具体事实与定位；词形来源用 `word_sources.csv`，避免重复存数千份同一考纲引用。每条事实须区分官方词形、词典或构词参考、原创讲解、真实试题和程序统计。不得给原创内容伪造外部作者或出处。

按词条记录基础、构词、句子、真题四组进度。状态为 `not_started`、`draft`、`validated`、`reviewed`；可选字段确实不适用时，记录理由后使用 `not_applicable`，没有找到资料且尚待研究时仍是未完成。表结构检查通过不能自动改为 `reviewed`。

每批交付时核对词表版本、字段组覆盖、来源、主外键及内容。跨会话先读 `PROGRESS.md` 和进度 CSV，再领取未完成词条。尚无证据的真题或词源可留空，但必须报告覆盖缺口；禁止写重复模板句或无意义文字来满足非空检查。

任何正式 `words.csv` 记录只有在该词必填教学内容已复核、可选项状态已说明、引用和计数检查通过后，才能标为 `detail_status=ok`。阶段 1 的词表本身不能冒充已经完成的教学内容。
