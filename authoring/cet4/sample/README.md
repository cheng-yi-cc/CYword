# 四级 30 词样板

本目录是阶段 2 的人工编辑源与确定性导出物。`batch-001.json` 至 `batch-003.json` 各含 10 词；`manifest.json` 解释选词覆盖面；`book/` 由脚本生成，不在生成文件上手改。

每词至少包含一条普通例句、一条搭配和一条带结构分段的长句；真题与词频因本阶段没有建立可核验语料而保持零行。关系表只连接本样板中的词，以便现有读取逻辑能完整消费。真正词根、前缀、后缀和词基统一引用上级目录的 `morpheme_registry.csv`；同形的 `port`“运送”词根与 `port`“港口”词基使用不同 ID。

在仓库根目录运行：

```powershell
npm run cet4:sample:build
```

该命令依次重新导出 19 张 CSV、执行结构检查及 6 个反向错误样例，再用现有应用数据编译器把结果写入 `.work/cet4/stage2-data/`。它不会覆盖正式六级 `data/`，也不会把样板冒充完整 `books/cet4/`。
