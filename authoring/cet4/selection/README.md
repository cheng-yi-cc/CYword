# 四级选词审计

本目录落实“候选名单与考纲对照，再固定范围”，不把候选词典和考纲取并集。考纲冻结清单仍是上级 `wordlist.csv` 的 6,161 条。保留独立派生词和基础词，不为使四级数量小于六级而删词。

- ECDICT 固定版本中有 3,849 个 `cet4` 标签候选。3,395 个候选行对应本表 3,383 个唯一学习词条；拼写变体会造成行数与词数不同。454 个候选没有命中本表，不自动增加。
- 与现有六级精确同词 3,311 个，声明拼写变体再匹配 14 个，共 3,325 个；四级独有 2,836 个，六级独有 1,841 个。仅建立审核入口，不能当作正文复用量。
- 189 个被词形字段提示的词逐条写入 `inflection-decisions.tsv`。其独立名词、形容词义、不规则比较形式及考纲单列情况见 `inflection_review.csv`。AIDS、evening、number、politeness、stranger、weed 等不能直接接受词典给出的机械原形。

`summary.json` 保存固定提交和源文件、冻结词表的哈希。`crossbook.csv` 是逐词交叉表，`cet6_only.csv` 保存六级差集；`ecdict_candidates.csv` 保存所有候选的命中或排除结果。生成文件由 `npm run cet4:selection:audit` 重建，人工决定在 TSV 中修改。

本次词形筛查未发现需要删除的目标词，因此范围保持不变。该结论只覆盖收词理由，不表示 6,161 词的释义、构词和助记已全部审核。
