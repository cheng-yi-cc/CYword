# 四级 100 词应用试验

在项目根目录运行 `npm run cet4:pilot`，访问 **http://127.0.0.1:5189/**。此入口使用现有学习界面，含 30 个原已核查样板和 70 个待复核初稿。它用于检查阅读、跳转和学习顺序，不是正式完整四级词书。

本次为 70 词补齐 210 个阅读片段释义，加上原样板共 300 个片段；登记 43 条明确的前置词依赖，检查不存在未知词、自环或循环，并验证实际排课中的先后顺序。`reading-glosses.tsv` 与 `policy.json` 是人工编辑源；`dependencies.csv`、`manifest.json` 和未提交的 `entries.json` 是生成物。

试验只采用已经登记的真实构词。70 个草稿尚未核实的拆分暂不登记，不能把“尚未登记”理解成“没有词根”。一个目标词的词根保留在详情中，本试验仅将关联至少两个目标词的词根单独编组。当前为 88 组、100 次学习曝光，3 个学习日和 1 个累计复习日；正式词书的天数另按完整数据计算。

词书及应用生成物放在 `.work/cet4/pilot-book/` 和 `.work/cet4/pilot-data/`，试验进度使用独立浏览器键 `cyword-cet4-trial-progress-v1`。服务启动时加载词书快照；修改源数据后重新运行启动命令。六级正式 CSV、账号和学习进度不在本试验写入范围。
