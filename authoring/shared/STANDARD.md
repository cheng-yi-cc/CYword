# 共用词汇内容标准

依据用户在 2026-09-17 采用的《四级词汇整理方案》（任务 `6aab4728-9fc8-83ee-a584-7f3ef51a7fd9`）。本标准同时约束新四级内容和今后经过审核的六级修订；六级原文不是正确性依据。

## 收词

按确定版本的目标词表收录独立单词和派生词，保留基础词。普通屈折形式进入原词词形信息；如果官方单列且有独立义项、不规则用法或本表没有另收其原形，则逐词记录保留理由。书外辅助词不增加目标词数。候选标签不与考纲直接取并集，不按四级应少于六级的数字预期删词。

## 释义与例句

统一使用 n.、v.、adj.、adv. 等词性缩写。先给学习者最需要的常用义；不同读音和词性分别说明。词典原始译文存参考层，不自动成为成稿。普通例句及长句应覆盖本条核心义并适合四级；原创标为原创。缺真题、音频和考试词频时留空，不拿通用词频替代考试词频。

## 拆解与记忆

每词选一个主记法，依次考虑有依据的浅层构词、熟词联系、简短场景、字形或谐音。短词可只用一句提示，联想很费解时直接整体记。深层历史词源可以作补充，不强迫学生背完每个历史环节。

`memory_markup` 写怎样记；`etymology_markup` 只写有依据的构词事实。借字形、谐音或虚构场景时明确是联想，不从故事反推真实词根。禁止因单词末尾有 t 就登记 -t 为后缀。真实词根、词基、前缀、后缀保持各自类型，不用修改类型控制排课数量。

同一构词元素用 `morphemes.csv` 的稳定 ID、语言、类型和义项；同字母不同来源不得合并。六级旧 ID 通过逐词 `legacy_links.csv` 对照共用 ID；只审核过的具体用法可复用，不能全局替换一个混合义项的旧 ID。

## 关联与学习顺序

前置词以稳定 ID 记录在 `dependencies.csv`。一个链接只表示可查阅，不自动意味着必须先学。书外联想词仅作辅助，不进入依赖图。依赖自环、闭环、未知目标都必须阻止导出。

真正词根是否参与课程另外判断。多目标词、有清楚核心义和易懂代表词的词根优先；只有一个目标词的词根默认在详情展示。第一版六级现有排课保持兼容；改变旧词根组须单独迁移旧计划与学习进度，不能混入四级导出。

## 复用与审稿

六级同词仅建立审核入口。音标、义项、真实构词、巧记和前置词分别决定能否复用。保留具体好方法，不复制模板腔、缺图提示或未经核实的词源。未取得可再分发依据的第三方正文不纳入公开新增内容；本地对照与原创写作分开。

结构校验只证明文件和引用可用。语言、构词和教学选择的审核记录独立保存；用户认可状态与代理的内部审核状态分开。没有完成全量正文时不得发布为完整四级词书。

## 已核查的写法样本

| 六级条目 | 可继承的方法 | 四级落实 |
| --- | --- | --- |
| ability | 联系 able，交代 abil 的字形变化 | 使用现有 able → ability 样板，一句话落到能力 |
| action | 用导演喊 Action 的场景唤起行动 | 可作场景备选，主记法和 act 保持单向依赖 |
| accompany | 联系 company 的陪伴义 | 只取熟词联系；不沿用未经核验的深层拆分 |
| abandon | 字形可借 a band on | 明确只为拼写联想，不把 a、band、on 登记为词源 |
| eat | e 的开口形状可作联想 | 禁止沿用 -t 是动词后缀的说法；核对 Collins 的古英语 etan 记录 |
| inspect、expect | 联系“看”的词族 | spect / spec / spic 按核实后的身份关联，末尾 t 不再单拆 |

事实核对入口：现有 `cet4/evidence.csv`；[eat](https://www.collinsdictionary.com/dictionary/english/eat)、[expect](https://www.ahdictionary.com/word/search.html?q=expect)。样本是本轮编辑筛选，并非声称用户已经逐条认可。
