# 六级记忆增强数据

本目录是独立增强层，覆盖可枚举的全部 **5166** 个单词。原 19 张 CSV、巧记正文、词根正文和引用保持原样。包含以音记形和以熟带生。

## 数据与读音约定

- `pronunciation-guides.jsonl`：每行一个词，以 `wordId` 关联 `words.csv`。`sourcePronunciation` 保留原始音标快照；`guide` 保存完整音标、顺序拼写块、各块音标、主/次重音及提示。
- 每词沿用原词书的读音，不强制统一英音或美音。将 ASCII 重音、冒号等记法规范化；已确认的音标错配和遗漏另存于 `correction`，共 94 条，包含原因和参考链接，不覆盖原表。
- 圆点是便于记忆的连续拼写分块，不宣称是词典断字或严格音节边界。例如双写辅音可分置两块，但只读一个辅音；成音节辅音不强加原音标没有的元音。弱读合并、跨块字母组合及不规则词允许附提示。
- 完整音标及原整词音频保留。点选分块只突出对应拼写与音标，不截取音频、不生成单块读音。音频未逐词听审，不保证原录音口音与音标完全一致。

## 本次验收范围（2026-09-20）

逐项浏览了 5166 个词的拼写分块清单，对不发音字母、辅音对应、重音冲突、复杂元音和异常长块进行复核；41 个词另作边界/提示修订。5120 个词附有 CMUdict 参考读音，46 个词没有 CMUdict 对应项，沿用原词书音标。英美差异不作为自动纠错依据。

`pronunciation-review.jsonl` 为每词记录内容哈希、检查项和参考。`accepted` 表示通过本项目的音形对齐及异常复核，**不表示 5166 个词均逐一查过独立词典或听过录音**。哈希用于阻止修改后沿用旧验收记录，不能证明语言学正确性。

`npm run data:verify` 在每次构建前逐词校验：全覆盖、唯一 ID、原文快照、拼写无损还原、音标无损还原、重音数量与归属、提示格式及验收哈希。`npm run data:audit:pronunciation` 另输出可逐条查看的 `.work/pronunciation/acceptance.json`。尚未涵盖每个多音词的所有词性/口音变体，只解释本条完整音标对应的读法。

## 维护

1. `node scripts/generate-pronunciation-candidates.mjs` 仅生成 `.work/pronunciation/cet6-candidates.json`，所有候选标为 `needs-review`，不覆盖正式数据。它是规则候选器，不是语言学判定器。
2. 逐词核对候选与现有增强条目；有明确来源才纠正原音标，保留理由和链接。音形不能可靠细分时保留更大的对应块，不能强拆字母组合。
3. 将确认后的条目写回同一个 JSONL；重新审核该词，并用 `pronunciationHash(record)` 更新对应验收行。不要整表自动标记审核通过。
4. 运行数据校验、逐词报告和测试，再编译。增强字段可选，其他词书没有增强文件时按原界面显示。

## 来源与许可

音标基线来自原词书。异常参考 [Cambridge Dictionary](https://dictionary.cambridge.org/)、[Collins Dictionary](https://www.collinsdictionary.com/) 及 [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict)。各纠正条目保存具体来源 URL；只记录必要读音事实，不复制词典释义正文。

CMUdict 快照下载于 2026-09-20，`cmudict.dict` SHA-256 为 `81917843c7f44ce2b094ac63873c2c7a4cf802040792c455ba3ca406891c3d22`。原许可见 [CMUDICT-LICENSE](CMUDICT-LICENSE)；发行包同时携带 `third-party/CMUDICT-LICENSE.txt`。

## 以熟带生（2026-09-20）

逐对审查原关系表中能定位到本书词条的 859 对近义/反义候选，再浏览其余词条的释义，补充直接的词义联系。共保存 1584 对审核记录：1466 对通过、118 对排除；另有 202 条补查建议的参照词不在本书，保留排除原因，不进入展示数据。原表的派生关系不冒充近义关系。每条提示写明适用词义或区别，不表示两个词在所有语境都能互换。

- `meaning-bridge-reviews.jsonl`：逐对保存原关系行、两端释义快照哈希、接受说明或排除理由；补充关系注明来源为本书释义审查。
- `meaning-bridges.jsonl`：5166 条逐词结果，其中 2180 词有候选、2986 词本轮未选出候选；不是声称这些词不存在任何近义或反义词。
- `meaning-bridge-word-review.jsonl`：5166 条逐词审查记录，绑定对应结果哈希，并保留补查排除建议。
- `book.json.meaningBridgeEnhancement`：指定三个源文件；校验器检查全覆盖、端点、原文快照、审核状态、词义说明和结果一致性。哈希只用于防止旧审核沿用，不能证明语义绝对正确。此次语义审查基于现有词书释义，未逐词查独立词典。

熟词范围为同一本书中排在当前学习位置之前的词（不要求实际评级），以及已有学习记录的词（包括未掌握、不清楚）。学习页按本次曝光位置，详情和复习按该词首次位置判断；实际学习记录均可补充。每次只显示一个参照，优先实际学过且已掌握的词，其次其他已学词，再按计划先后选择。没有合格参照时整个板块隐藏。板块位于词根词缀分析之后，支持鼠标、键盘和点按悬浮卡；复习揭晓前不显示。增强关系不参与重排，也不写入学习记录。

维护时先逐对核实并修改同一审核源，再运行 `node scripts/audit-meaning-bridges.mjs --compile` 重建逐词结果；复核受影响词后更新对应 `recordSha256`，不得未经审查批量续签。随后执行 `npm run data:build` 和 `npm run data:audit:meaning-bridges`。后者逐词对比编译结果、原巧记与词源正文，并输出首次位置下的显示/隐藏原因到 `.work/meaning-bridges/acceptance.json`。
